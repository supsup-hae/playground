# 브랜드 마크

형태와 색의 기준은 [`tool/app_icon.py`](../../tool/app_icon.py) 하나다. 이 폴더의 SVG, macOS·Android 아이콘은 모두 그 스크립트가 만든다.

```sh
python3 tool/app_icon.py            # SVG + Android 벡터 + macOS/Android PNG
python3 tool/app_icon.py --svg-only # SVG + Android 벡터만
```

## 아이디어

후지 바디처럼 **실버 상판 / 블랙 바디**로 나뉜 다이얼. 두 면의 경계가 왼쪽으로 열린 **슬롯**이 되고, 슬롯 안의 **점 7개가 C1–C7**이다. 가장 바깥(입구) 점만 빨강으로, 지금 슬롯에 들어가는 레시피를 가리킨다. 나머지 여섯 점은 상판과 같은 실버다.

## 구성 (256 격자)

| 요소 | 값 |
|---|---|
| 다이얼 | 중심 (128, 128), 반지름 104 |
| 경계 | y = 112 (중심보다 16 위, 상판이 바디보다 작다) |
| 슬롯 | 높이 20 (y 102–122), 왼쪽 끝까지 열림, 오른쪽 끝 x = 138 에서 반원 |
| 점 | 반지름 4.5, x = 40 + 16n (n = 0…6), n = 0 만 빨강, 나머지는 실버 |
| 앱 아이콘 | 흰 타일 (모서리 57/256), 마크 74%, 4/256 위로 |

**작은 판 (32px 이하)**: 점 7개가 뭉개지므로 슬롯 높이 36, 빨간 점 하나(반지름 12)만 남기고 마크를 84% 로 키운다. macOS 16·32px, Android mdpi·hdpi 레거시 아이콘이 이것을 쓴다.

## 색

| 이름 | HEX | 쓰는 곳 |
|---|---|---|
| 실버 | `#CFCBC4` | 상판, 슬롯 안 점 |
| 바디 | `#17191C` | 바디 |
| 브랜드 빨강 | `#D7282F` | 아이콘·로고·인쇄의 빨간 점 |
| 화면 빨강 | `#EA4A35` | 앱 화면의 강조색(`AppColors.accent`). 어두운 바탕 4.5:1 이상 |
| 타일 | `#FFFFFF` | 앱 아이콘 바탕 |

빨강은 점 하나에만 쓴다. 마크 안에 빨강을 늘리지 않는다.

## 파일

| 파일 | 용도 |
|---|---|
| `app-icon.svg` | 앱 아이콘 (64px 이상) |
| `app-icon-small.svg` | 앱 아이콘 (32px 이하) |
| `mark.svg` | 타일 없는 마크, 밝은 바탕 |
| `mark-on-dark.svg` | 어두운 바탕 (상판·점 `#ECE9E4`, 바디 `#34373C`, 빨강은 화면 빨강) |
| `mark-greyscale.svg` | 흑백 인쇄 |

## 하지 말 것

- 상판과 바디의 위아래를 바꾸거나, 경계를 기울이지 않는다.
- 점 개수를 바꾸지 않는다 (7 = C1–C7).
- 빨간 점을 슬롯 안쪽 끝으로 옮기지 않는다 (가장 바깥이 기준).
- 32px 이하에 큰 판을 쓰지 않는다.
- 그림자·그라데이션·외곽선을 더하지 않는다 (macOS 아이콘의 옅은 그림자는 예외).
